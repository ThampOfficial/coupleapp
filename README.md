# บันทึกของเราสองคน (Couple App)

เว็บแอปไดอารี่สำหรับคู่รัก (ภาษาไทย)

- นับว่าคบกันมากี่วัน / กี่ปี กี่เดือน กี่วัน และนับวันแต่งงาน
- ไทม์ไลน์: เจอกัน, วันนี้ทำอะไร, ไปเที่ยว, ครบรอบ, แต่งงาน, อื่นๆ พร้อมรูป
- แผนที่สถานที่ที่ไปด้วยกัน (จิ้มบนแผนที่ หรือวางลิงก์ Google Maps)
- วันสำคัญ: ครบ 100 / 500 / 1,000 วัน, ครบรอบปี, ครบรอบแต่งงาน คำนวณให้อัตโนมัติ

## การเก็บข้อมูล
- เปิดเป็น Claude artifact: บันทึกออนไลน์ แชร์กับแฟนได้
- เปิดจากไฟล์นี้ตรงๆ หรือ GitHub Pages: บันทึกไว้ในเบราว์เซอร์นั้นเท่านั้น (localStorage)

ไฟล์เดียว: `index.html`
